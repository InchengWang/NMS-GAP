# Gap Validation for Human NMS Embodied AI

This directory validates ten candidate gaps derived from the 49-paper Embodied-AI critique. Every dossier includes a kill-oriented counter-evidence search and the nearest existing work.

## Files

- [`GAP_VALIDATION_REPORT.md`](GAP_VALIDATION_REPORT.md): full gap dossiers and proposal recommendations.
- [`COUNTER_EVIDENCE_LOG.md`](COUNTER_EVIDENCE_LOG.md): query families, strongest counter-evidence and search limits.
- [`data/embodied_ai_gap_validation_matrix.csv`](data/embodied_ai_gap_validation_matrix.csv): machine-readable ten-gap matrix.

## Verdict summary

| Verdict | Count |
|---|---:|
| `confirmed-open` | 1 |
| `partially-addressed` | 7 |
| `not-a-gap` | 2 |
| `speculative-opportunity` | 0 |
| `out-of-scope` | 0 |

The only `confirmed-open` candidate is deliberately narrow: longitudinal **patient NMS state + controller co-adaptation**, with fast/slow change separated and validated by both mechanistic and rehabilitation outcomes. The report does not claim that co-adaptation, adaptive rehabilitation robotics or patient-specific control are individually absent.
