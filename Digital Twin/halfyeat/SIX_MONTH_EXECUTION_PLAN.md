# 留在 Hayashibe 组的半年执行计划

日期：2026-10-05。计划窗口约2026年10月—2027年3月；W1–W24按从启动周开始的相对周编号，不假定每个自然月恰为四周。目标：完成SII2027可提交期刊稿、第三篇独立研究稿，并交接博士启动所需的可复核资产。投稿后的录用与审稿周期不设为验收条件。

## 1. 优先级和工作预算

**必须先完成：** 输入/标签/数据谱系审计 → 同协议SII对照 → 期刊稿；第三篇的主实验必须通过独立参考和精确问题gate。EMG、力板、真实跨日患者采集或机器人均不是已经确认的资源。

以下工时按每周约15–20小时用于这条研究线的规划假设，24周约360–480小时；并非对你实际可用时间的认定。必做工作包合计约340小时，真实重戴和NMSpilot最多再约64小时，其余留给失败重跑、共同作者核验及已有学位工作。单项工时为计划值，不代表训练排队/审批时间。

## 4. 首两周可以立即执行的任务

| 顺序 | 动作 | 完成标志 |
|---|---|---|
| T01 | 为每个原始trial建立人/日期/通道/同步/配对ID | 真实、mocap、合成、标签能被同ID追踪 |
| T02 | 打开真实test特征生成代码，定位骨盆R与sensor orientation来源 | 每项测试输入标“仅传感器/静态校准/动态参考”；写成来源表 |
| T03 | 检查真实与虚拟原始group跨train/validation/calibration/test的交集 | 所有同轨迹派生数据留在一组；不能仅查文件名 |
| T04 | 定位LR选择、早停、ratio选择和融合设置日志 | 明确各设置看过哪套数据；test若已使用则另设验证或限定为探索 |
| T05 | 导出8人×所有试次×8角度的预测/参考与指标 | 查清0.9974、2.968°和Table II/III/VI的聚合关系 |
| T06 | 对一条已知姿态/运动检查符号、零点、角度投影与SO(3) | 图和定义一致；确认是否仅投影角而非完整JCS |
| T07 | 固定部署版本输入，跑最简单direct回归与原版上界 | 区分输入参考优势与网络优势；先看失败例再扩大训练 |
| T08 | 明确第三篇ROM参考、重复误差、额外真实通道/重戴是否可用 | 独立参考存在；ε与追加观测是具体可实施条件 |

这些是研究执行清单，不表示本次已经取得原始数据、运行了模型或完成采集。

## 6. 交接与博士启动包

交接应包含：合法使用范围与不可公开项；participant/trial manifest；特征/坐标/同步说明；固定split与所有调参记录；模型/依赖版本和入口；结果明细到主表的生成方式；每个claim到实验和最近邻的对应；未通过的gate、失败例与替代路线。

博士启动的前三项：确定一个机械/交互任务和外部参考；选至多4–6个可辨识参数；用锁定未见条件检验参数是否有预测价值。UWB、IMU或视觉的选择只在对该状态增加信息时进行。传感硬件路线不能替代神经肌肉机制或具身动作问题。
