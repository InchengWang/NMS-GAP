# 第三篇文章：任务可靠性与补充观测的价值

日期：2026-10-05。计划依赖 SII2027 的 P0 输入/拆分/指标审计；所有结果均待开展。最近邻 R01–R14 见 [来源与 gap 账本](SOURCE_AND_GAP_AUDIT.md)。

## 1. 推荐题目及独立问题

**中文工作题目：** 面向个体运动反馈的任务导向可靠性与主动补充观测：从稀疏重建到可拒答的交互状态估计

**英文工作题目：** Task-Directed Reliability and Selective Sensing for Personalized Human Motion Feedback

研究问题：**当稀疏观测下的运动重建出现个体、佩戴或数据缺失变化时，模型能否识别指定反馈任务已经不可靠，并以有限的额外观测或标定成本恢复有效输出？**

主任务默认选择“患侧膝关节 ROM 及其相对个体基准的变化反馈”。它可以利用现有下肢运动参考，且和患者状态相关。它不是临床诊断标签，不承诺改善恢复。半年内主要决策为报告、复核/追加观测、暂不反馈；人体辅助力矩控制留到博士阶段。

| 工作 | 主要对象 | 验证单位 | 第三篇相对增量 |
|---|---|---|---|
| BSN P1 | 未测小腿 IMU 波形与事件一致性 | 信号/实测小腿算法 | 波形一致性不能直接判定反馈可靠；增加独立任务参考与错误接受分析 |
| SII P2 | 有限标定下的关节运动重建 | 每角度、患者与试次 | 不重复以新网络降低平均 RMSE；固定基本重建协议，检验任务风险和观测成本 |
| 第三篇 | 任务所需信息及错误反馈是否可识别 | 患者/完整试次/反馈决策 | 比较同有效输出率下的错误率，及同额外观测成本下的恢复价值 |

如果第三篇只剩同一测试集上增加 uncertainty head、一个 ROC 图或几种 dropout，应合并到 SII 期刊稿。独立成篇需要完整任务、合理最近邻、冻结失效条件和至少一种可复核的恢复动作证据。

## 2. Gap 与 novelty 边界

继承 G07、G05/EAI-G04 的 **partially-addressed** 残余；不使用 EAI-G07（“重建 IMU 是具身智能空白”，原 verdict 为 not-a-gap）。

R06（张明明组 OEEL）已做开放环境不确定性与 risk–coverage；R07 已做临床运动学校准及不可靠步态结果剔除；R08 已将 NMS 置信界用于辅助。R09 的拒答与 R10 的时序区间也是现成方法。因此贡献应限定为：

> 在个体下肢重建链条中，以独立运动参考定义任务错误，检验误差传播和输入变化下的可靠度，并比较拒答、追加观测与再标定的成本—任务效果。

这是本次检索支持的**候选联合贡献**，不是“首次可靠运动估计”。如果后续找到同样的运动状态、变化条件、恢复动作和独立验证组合，需改变实验问题或降为复现/外部验证贡献。

## 3. 可证伪假设

H3a：与信号 RMSE/PCC 排序、确定性质量规则和未校准模型不确定性相比，基于任务误差校准的选择机制，在 **80% 有效输出率**下减少 ROM 反馈超过预设容许误差的比例。

H3b：在相同追加观测次数/时间预算下，按任务不确定性触发的追加观测，比固定周期或随机追加更有效地恢复可靠 ROM 输出。

H3c：在没有测试参考输入的估计链条中，模型/传感几何约束可以改变失效排序，但不保证所有病理个体、佩戴漂移均可被可靠检出。若 H3a/H3b 不成立，就报告失效原因和适用边界，而不是将每一种置信度输出包装成成功。

80% 是预先选择的工程比较点，不是临床安全阈值；同时给出 50%–100% 的 risk–coverage 曲线。阈值、误差容许量及主对比均在锁定测试前冻结。

## 4. 数据和参考门槛

第一步盘点两稿是否使用共同原始试次。只有同一原始轨迹经同步、坐标和通道校验，才能做 BSN→SII 诊断级联；P1 的 acc/gyro 不能直接当 P2 的 acc/orientation。级联不是主路径，无法可靠转换时删除。

| 数据层 | 必要内容 | 可支持的结论 | 不可支持的结论 |
|---|---|---|---|
| 必做：既有真实 IMU+mocap | 完整试次ID，真实输入，无测试 mocap输入；独立运动参考 | 同数据范围内任务误差、跨试次泛化及模拟故障敏感性 | 实际重新佩戴、跨日或临床控制安全 |
| 首选补充：真实重新佩戴 | 按可用伦理与设备，6–10名健康成人工程pilot；至少两次取下重戴，若能跨日期则记录真实日期；同步运动参考 | 真实佩戴变化下的工程有效性；支持流程是否可执行 | 健康pilot结果不能直接迁移为卒中有效性 |
| 机会补充：现有卒中随访 | 仅在既有合作、可用许可和采集安排中已有后续访问时纳入 | 卒中重新佩戴/日期改变的描述性个体证据 | 不假设六个月可新招募大队列或获得恢复疗效 |
| 博士扩展 | EMG、GRF/测力、单关节交互平台及独立条件 | 运动学→NMS参数→动作价值的渐进检验 | 仅角度参考不能验证肌力、神经驱动或组织负载 |

6–10 是工程 pilot 的排期建议，不是功效计算结果。已有卒中主结果只明确8人；最终可用人数由数据审计确定。若真实重新佩戴采集无法在 W8 前落实，将它从半年强制项移除，并明确第三篇仅为离线任务可靠性研究。

参考 ROM 定义必须和估计一致；临床 JCS 与投影角不混用。使用独立 mocap处理管线得到参考，而不是实测小腿IMU同算法结果。事件任务仅在已有或独立验证过的接触参考可用时作为次终点；没有力板/足底接触标签就不称接触真值。

## 5. 方法和动作

### 5.1 状态与任务表示

从 SII 的可部署版本输出关节运动状态、质量信息和预测分布。状态层接口以解剖定义和单位组织，后续可接位置/视觉/UWB/IMU；半年实现可使用当前 IMU数据，博士研究逻辑不绑定它。

每试次输出 ROM：`r = max(q_knee) − min(q_knee)`。以独立参考 r* 定义技术任务错误 `e_r = |r − r*|`。容许量 ε_r 在开发集上依据重复测量误差及实际使用要求制定并冻结；可预注册 3°/5°/8° 敏感性点，但不能声称这些是公认 MCID 或临床安全界限。

### 5.2 基本可靠性机制

先用固定重建器上的 deep ensemble 或预先选定的概率输出模型，传播分布到 ROM。比较未校准宽度、独立试次残差校准、任务级直接校准；必要时加解剖约束违反量和原始信号缺失信息。没有独立消融收益就不用复杂融合。

训练/超参数验证/区间校准/最终测试必须区分。小数据时用分组 cross-fitting 产生开发残差，但不使用任何外层测试标签。不能把高度重叠的时间窗当作独立 conformal calibration 样本。

普通 split conformal 的有限分位数在独立 calibration 单位不足时会退化：例如 95% 水平少于19个校准单位可能没有有限的非平凡区间。此时采用较低水平、开发群体的经验区间或报告不可用；跨患者和漂移下只报告实测覆盖，不给无条件、患者级“分布无关保证”。R10 有时序方法先例，不能替本研究证明其假设。

### 5.3 恢复动作与公平预算

| 动作 | 半年实现 | 正确评价方式 |
|---|---|---|
| 报告 | 输出 ROM 和区间/质量标记 | 以外部参考统计错误接受；同时报告保留比例 |
| 追加观测 | 若同试次额外腰部/足部流真实存在，启用预先训练的更丰富输入估计器 | 完整记录额外通道与成本；不按外部标签选传感器；这是回放式传感获取，不是真实动作改变 |
| 再标定 | 仅使用之后合法取得的标定池，更新后评价另一个锁定未来试次 | 不能把当前测试的真值作为“重标定”再回头评分；没有时间序列数据则只比较独立预算曲线 |
| 暂不反馈 | 保留观测异常说明，等待恢复条件 | 全部拒答不能获胜；风险曲线、覆盖率及成本共同评价 |

先完成“报告/拒答 + 额外真实通道回放”，再决定是否做再标定。不得以一个离线 confidence gate 声称真实外骨骼控制安全或临床交互获益。

## 6. Baselines 和实验矩阵

| 基线/实验 | 排除的替代解释 |
|---|---|
| B1：相同重建器总是报告 | 改善是否仅来自少输出 |
| B2：原始信号缺失/幅值/姿态突变规则 | 简单传感质量检查是否已足够 |
| B3：未校准 ensemble、模型残差/约束评分 | 校准与任务定义是否有额外作用 |
| B4：任务级经验/分组残差区间；适用时 EnbPI 或 selective predictor | 拒答/区间既有方法不能被当作新算法；R06/R07用于原理比较，若无原实现则明确为思想适配而非逐项复现 |
| B5：同成本固定周期、随机追加观测 | 主动获取是否优于简单预算安排 |
| B6：真实额外输入和参考辅助上界 | 可恢复上限及不可观测任务；上界不计为部署方法 |
| X1：真实留出试次/日期 | 外部迁移；只有日期真实不同才叫跨日 |
| X2：真实重戴；模拟 rotation/dropout/latency 另列 | 区分实测与注入故障；旋转需一致作用于相关原始通道/姿态，不随意独立打乱矩阵元素 |
| X3：直接 sparse→state vs virtual signal→state 诊断 | 虚拟信号误差是否传递到任务；仅通过接口审计才做，不以简单串联为 novelty |
| X4：相同信号/角度误差区间下的任务失效 | 平均 RMSE 好不一定代表任务可靠；防止选择容易病例制造收益 |

## 7. Metrics 与统计分析

**主终点：** 预定义80%覆盖率下，接受的完整试次中 `e_r > ε_r` 的比例；主对比是任务校准机制 vs B3 未校准不确定性。80%排序评价使用测试质量分数但不使用测试标签确定阈值；它是离线公平比较点。实际部署操作点另在验证集锁定，测试报告实际覆盖率，不能保证恰为80%。

**次终点：** risk–coverage/AURC、预测区间 empirical coverage 与宽度、ROM MAE/bias、错误变化方向、每次追加观测恢复多少可靠输出、标定分钟数、输出延迟和最差个体。将“错误接受率”称为技术任务风险，不用“临床 false-safe”替代。

统计单位为参与者，完整试次是其内重复观测。每位患者先形成主指标与配对差，患者等权汇总；配对精确/秩检验和患者 cluster bootstrap 区间作为小样本推断。少量二项事件的区间可能很宽，报告分母、全部患者点和可用试次数。运行seed先在患者内汇总，避免伪重复。

健康重戴pilot和卒中既有数据分开汇总。使用探索性分层分析审计侧别、速度和误差幅度，不能因组内窗口很多而宣称病理群体有效。ε_r多点、多个覆盖率和多个失效条件均为敏感性分析；主点提前固定，次比较Holm校正或明确描述性。

## 8. 早期 kill tests、替代路线与贡献

| 时间 | Kill test / 早期信号 | 替代路线及失败价值 |
|---|---|---|
| W2 | 独立任务参考不存在；或测试输入仍含 mocap 骨盆 | 先修 SII；第三篇不能建立在参考泄漏或循环标签上 |
| W6–8 | 不确定性排序不优于 B2/B3，或区间宽度近似全拒答 | 报告“波形精度不能保证任务可信”的边界；简化模型，评估约束/额外观测是否有价值 |
| W8 | 没有真实日期/重戴数据，也无法新增 | 主张限于跨试次和模拟故障；若只有常规补充图，合并SII，不强行拆第三篇 |
| W12 | 额外观测收益仅来自更多固定信息，主动选择不优于固定预算 | 保留任务所需观测的条件边界，取消主动感知成功 claim |
| W16 | 精确最近邻已包含全部联合条件 | 做可复核的外部患者验证/可部署输入比较，或转为博士 Aim 2 的可辨识性 pilot |

可能贡献为：任务风险与感知/标定成本的联合评价；个体重建误差传播及失败案例；一个锁定协议与轻量软件接口。若只有运动学、没有神经/肌肉参考，称“个体运动状态可靠性模型”或“数字影子组件”。**不能称为已经完成的 NMS 数字孪生或具身控制系统。**

半年内目标为第三篇完整研究稿及可复现实验包，投稿以证据gate为条件。首选Sensors Journal类传感/估计方向；只有独立康复功能和患者验证充分时考虑TNSRE。第三篇不是用来替代 SII 的必要消融。
